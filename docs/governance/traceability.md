## How to read this matrix

- **Requirement** — a stable FR/GAR/AR/NFR/SC identifier from `spec.md`. Every identifier defined in the spec appears exactly once (no silent inventory drift).
- **Task(s)** — the governing task ID(s) from `tasks.md` that cite this requirement. Every listed task ID is verified to exist in `tasks.md`.
- **Test / Artifact** — the on-disk implementing artifact and its test(s). A path is listed here only when it exists on disk AND (for governed contracts) is recorded `present` in the signed evidence manifest `evidence/manifest.json`.
- **Evidence** — how the row is independently observed: a Vitest/node test suite, the signed manifest record (sha256-pinned), and/or a `GATE<N>-EVIDENCE.md` gate record.
- **Status** — `present` when a built, tested artifact backs the requirement in this bundle; `planned` when the governing task is reserved for a later phase (its artifact is recorded `planned` in the manifest and is not represented as complete).

GAR-010 discipline: a change to any row (add/rename/remove a requirement, task, test, or artifact) requires updating this matrix and re-approving the signed evidence manifest; `npm run test:traceability` blocks drift between the matrix and disk.
